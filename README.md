Chef's Menu Application (React Native & Expo)A React Native and Expo menu management application built for chefs to create, view, edit, filter, and analyse tasting and service dishes—including items such as Valrhona Chocolate Tart, Pan-Seared Duck Breast, Heirloom Burrata & Figs, and Wild Morel Risotto.   Core Requirements & Features1. Manage Menu ItemsAdd & Edit Dishes: Allow chefs to add new menu items, edit existing items, and update dish information.   Delete Dishes: Remove menu items cleanly.   Immediate Updates: Reflect edits, additions, and deletions immediately across the application.   2. Search and Filter Menu ItemsSearch by Name: Search menu items by dish name using an expandable search bar in the header.   Filter by Course: Filter dishes by Starter, Main Course, or Dessert.   Clear Filters: Clear active search queries or course filters to view all menu items again.   3. Display Menu StatisticsTotal Items: Show the total number of menu items.   Average Price: Calculate and display the average price across all menu items.   Count per Course: Display how many menu items are available in each course in a clear, readable layout.   4. User Experience & Code EnhancementsValidation & Feedback: Validate required fields, display clear error messages, and show confirmation feedback when a menu item is added.   Empty States: Show a clear message when no menu items have been added or match current search/filter criteria.   Consistent Layout & Reusability: Keep layout and styling consistent across screens while using reusable components and helper functions to reduce repeated code.   Project Structure (Example)Plaintext├── components/
│   ├── MenuHeader.tsx         # Title, active dish count, course tabs, expandable search
│   ├── MenuItemCard.tsx       # Dish card with edit/delete actions and tags
│   ├── MenuFormModal.tsx      # Add/Edit form with validation and feedback
│   └── MenuStatsCard.tsx      # Total items, average price, and per-course counts
├── utils/
│   ├── menuFilters.ts         # Reusable name search and course filter helpers
│   └── menuStats.ts           # Reusable statistics calculation functions
├── screens/
│   └── MenuScreen.tsx         # Main Chef's Menu view
└── App.tsx
